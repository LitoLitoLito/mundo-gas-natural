## 📌 Sobre el proyecto

**Mundo Gas Natural** es una aplicación web orientada a brindar información y orientación sobre las instalaciones de gas natural, con especial atención a la seguridad y al uso responsable de las instalaciones.

El proyecto busca presentar la información de manera clara, accesible y organizada, mediante una interfaz web moderna y adaptable a distintos dispositivos.

También constituye una oportunidad para aplicar y consolidar conocimientos de desarrollo web con React, JavaScript y herramientas del ecosistema moderno de frontend.

## ✨ Características

- 🌐 Aplicación web accesible desde el navegador.
- 📱 Interfaz adaptable a diferentes tamaños de pantalla.
- 🔥 Contenido relacionado con el gas natural y la seguridad.
- 📩 Formulario de contacto integrado.
- ⚛️ Componentes reutilizables desarrollados con React.
- 🚀 Publicación web mediante GitHub Pages.
- 🔄 Flujo de publicación automatizado con GitHub Actions.

## 🛠️ Tecnologías utilizadas

## 💻 Instalación y ejecución local

Para ejecutar el proyecto en tu computadora, necesitás tener instalado [Node.js](https://nodejs.org/) y Git.

### 1. Clonar el repositorio

Abrí una terminal y ejecutá:

```bash
git clone https://github.com/LitoLitoLito/mundo-gas-natural.git
```

### 2. Ingresar a la carpeta

```bash
cd mundo-gas-natural
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Iniciar el servidor de desarrollo

```bash
npm run dev
```

Vite mostrará una dirección local en la terminal, normalmente `http://localhost:5173/`. Abrila en el navegador para visualizar la aplicación.

### 5. Generar la versión de producción

```bash
npm run build
```

Este comando genera la versión optimizada del sitio dentro de la carpeta `dist`.

## 🚀 Publicación

El proyecto utiliza **GitHub Pages y GitHub Actions** para automatizar la publicación.

Cuando se envían cambios a la rama `main`, el flujo de trabajo instala las dependencias, construye la aplicación y publica los archivos generados.

El archivo de configuración del flujo de trabajo se encuentra en:

```text
.github/workflows/deploy.yml
```
